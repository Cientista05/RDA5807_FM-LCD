# Changelog

All notable changes to this project are documented in this file.

## 1.0.0 - 2026-07-27

- Added complete English source comments and documentation.
- Organized hardware and radio settings as named constants.
- Limited tuning to 86.0–108.0 MHz before sending a frequency to the radio.
- Made encoder direction exchange between the interrupt and main loop atomic.
- Simplified large-digit rendering without floating-point `pow()` calls.
- Added an include guard to the large-number header.
- Added GitHub repository files, wiring documentation, and project artwork.
