# Contributing

Contributions are welcome.

1. Fork the repository and create a branch for the change.
2. Keep the sketch compatible with the Arduino Nano and ATmega328P memory
   limits.
3. Use clear English names and comments.
4. Avoid long or blocking operations inside interrupt routines.
5. Compile the complete sketch and test tuning, stereo indication, and signal
   display on hardware.
6. Describe the hardware and library versions in the pull request.

Please keep unrelated changes in separate pull requests.
